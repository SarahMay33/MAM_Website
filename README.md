# Manitoba Agricultural Museum Website

A personal web development project recreating and redesigning the Manitoba Agricultural Museum website. The project focuses on building a clean, organized, and interactive multi-page website using front-end web technologies.

## About the Project

This project was created as a hands-on web development project to practice building a multi-page website for a real-world organization.

The website includes information about the museum, ways to support the museum, visiting information, events and programming, and a mock online gift shop experience.

This is a personal/student project and is **not the official Manitoba Agricultural Museum website**.

## Features

* Multi-page website with organized navigation
* About and museum information pages
* Donation and artifact donation pages
* Employment opportunities information
* Land acknowledgement page
* Plan Your Visit information
* Programming and events section
* Reunion and Stampede information
* Gift shop interface
* Shopping cart functionality
* Mock checkout page
* Fake payment confirmation for demonstration purposes
* Interactive elements using JavaScript
* Embedded/linked external resources where appropriate

## Technologies Used

* **HTML5** — page structure and content
* **CSS3** — styling, layout, and visual design
* **JavaScript** — interactive functionality
* **Git/GitHub** — version control and project management
